Uses

Module directory

Each “Uses” link points from a caller to a dependency. The directory covers the three operator routes above.

  • CLI dispatcher

    Routes the selected command after applying any profile override. Start here to follow a CLI request.

    hermes_cli/main.py

    Uses Profiles, Log reader, Sessions

  • Profiles

    Resolves a named profile and its data directory. The default profile and named profiles have distinct storage roots.

    hermes_cli/profiles.py

    Uses Profile paths

  • Profile paths

    Resolves the active Hermes home used by log and session readers. Inspect this module when two profiles show different histories.

    hermes_constants.py

    No outgoing connections in this map.

  • Log reader

    Lists logs for the active profile and tails entries by session, component, time, or severity. Component names resolve through the logger groups.

    hermes_cli/logs.py

    Uses Profile paths, Logger groups

  • Logger groups

    Defines the logger prefixes used for component filtering. Gateway messages can come from adapter namespaces as well as the gateway itself.

    hermes_logging.py

    Uses Profile paths

  • Sessions

    Lists stored conversations and resolves the workspace scope before querying session records.

    hermes_cli/sessions_cmd.py

    Uses Session DB

  • Session DB

    Provides the SQLite session store. Its default database location follows the active Hermes home.

    hermes_state.py

    Uses Profile paths
